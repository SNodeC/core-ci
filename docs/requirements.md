# Functional contract and requirement map

This is the acceptance catalogue for the proposed replacement, not certification of the current deployment. R01–R46 preserve the complete previously agreed catalogue. GitHub-only mechanisms may be removed; domain guarantees may not be silently weakened. Proposed policy changes are marked explicitly. Test families T01–T16 are defined in verification-and-cost.md. Implementation has not started.

## Accepted policies versus decisions still required

Preserved: exact direct tags; source-owned graph; independent rows; lineage-free dependent gate; terminal retention; conditional revision sharing; publication serialization with spare-capacity builds; authenticated reports; byte validation and receipt idempotency; highest-only status.

Proposed changes needing design approval: configured own-worker budgets instead of full-organization occupancy; asynchronous MariaDB persistence; OIDC/authenticated worker protocol; the publication commit fence described in architecture.md; status-export responsibilities; deployment ingress for jupiter. No production SNodeC change is authorized by the sandbox design.
